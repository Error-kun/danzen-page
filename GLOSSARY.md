# Danzen landing

Terms for the GitHub Pages site and the landing README.

danzen-page is GitHub-only and is not under the four-host rule.

## Language

**Canonical landing source**:
The private `demi-code/danzen-page` repository treated as the source of truth. Every landing edit happens here.
_Avoid_: deployment fork, page mirror

**Landing deployment mirror**:
The public `Error-kun/danzen-page` repository that GitHub Pages builds from; live at https://error-kun.github.io/danzen-page/.
_Avoid_: canonical landing, origin

**Fork parent**:
The upstream project Danzen forked from. That project is Dartotsu.
_Avoid_: Upstream (alone), parent repo

**Inspiration line**:
The three apps named as design influences: Saikou, Dantotsu, and ReDantotsu. It appears once, in the single sentence “Danzen is a fork of Dartotsu, inspired by Saikou, Dantotsu, and ReDantotsu.”
_Avoid_: Credits, shout-outs, contributor list

**Public face**:
The GitHub Pages landing site and the README in this repository.
_Avoid_: Marketing site, homepage (alone)

**Release build**:
An installable Danzen application build shipped to users. Downloads exist only on the public app distribution mirror, `Error-kun/danzen`.
_Avoid_: Deploy, landing update

**Not released yet**:
The honest state of a project with zero public releases. It is what the download badge and the “Get the app” section say until a release exists.
_Avoid_: Coming soon (alone), placeholder download
