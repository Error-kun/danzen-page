# Danzen landing

Terms for the GitHub Pages site and the landing README in this repository.

## Language

**Fork parent**:
The upstream project Danzen forked from. That project is Dartotsu.
_Avoid_: Upstream (alone), parent repo

**Inspiration line**:
The three apps named as design influences: Saikou, Dantotsu, and ReDantotsu.
_Avoid_: Credits, shout-outs

**Superset**:
The Danzen app keeps every Dartotsu feature and already includes Saikou-line features.
_Avoid_: Merge, union

**Public face**:
The GitHub Pages landing site and the README in this repository.
_Avoid_: Marketing site, homepage (alone)

**Release build**:
An installable Danzen application build shipped to users.
_Avoid_: Deploy, landing update
